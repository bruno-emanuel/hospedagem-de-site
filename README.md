## 🌌 Sobre o Projeto

Este projeto foi desenvolvido para colocar em prática meus conhecimentos sobre **criação e hospedagem de sites**, entendendo o fluxo completo desde o desenvolvimento até o deploy.

Mais do que apenas subir arquivos, aqui eu aprendi:

- Como funciona o versionamento com Git  
- Como organizar um projeto real  
- Como enviar para o repositório remoto  
- Como funciona o processo de hospedagem  

E o mais importante:  
Estou realmente gostando da jornada de aprender programação.  

Cada `git commit` representa evolução.  
Cada erro corrigido representa crescimento.  
Cada push feito representa mais confiança como desenvolvedor.
